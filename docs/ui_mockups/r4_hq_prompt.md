## Final prompt

The original prompt follows below. Revision v2 uses the original concept image as an edit target, outputs `r4_hq_concept_v2.png`, and uses this prompt:

Edit this HQ game screen concept to have a much more appealing stylized management-game art direction. Preserve the general composition: left dark navigation, central clickable isometric racing team campus, right wind tunnel inspector, and bottom wind tunnel levels 1 through 5 comparison strip. Completely replace the photorealistic architectural rendering with deliberately stylized game art: chunky clean low-poly forms, softly hand-painted surfaces, broad readable shapes, subtle ambient occlusion, simplified trees and toy-like parked vehicles, warm friendly daylight, limited material detail, matte surfaces. Like a polished PC tycoon / city-building game with a miniature diorama campus. Slightly exaggerated recognizable industrial silhouettes. No photographic textures, no cinematic realism, no ray-traced glamour, no tiny visual noise. Still believable motorsport buildings, not fantasy or childish. Use green lawns, simple paved roads, blue-grey factory roofs, lightly teal glass, small team-colour accents. Keep dark charcoal UI and amber selected building outline. Every building should read clearly at normal game scale. Make wind tunnel recognizable by its large curved external duct. Show five clearly different architectural levels in bottom strip, from small shed to expanded game-like research complex, consistent camera and scale, same parcel bounds, distinct added annexes and equipment. UI text minimal and legible. This is a stylized game-screen concept, not an architectural visualisation.

## Original concept prompt

Use case: ui-mockup
Create a polished landscape game UI concept board for a realistic motorsport team headquarters management screen. Main upper 75% is a complete desktop game screenshot: dark charcoal navigation sidebar at left, restrained amber accents, header HEADQUARTERS with budget and date. Main scene is a beautiful static isometric / orthographic architectural miniature of a believable European racing team campus, daylight, landscaped grass, service roads, parking, glass design offices, industrial factory sheds, CFD data centre, and a distinctive wind tunnel hall with large external recirculating air duct. Realistic materials, carefully art directed 3D architectural game render, readable at game scale, no fantasy skyscrapers, no real brands. Buildings are individually clickable with small name and level badges. Wind tunnel selected with thin amber ground outline. Right-hand dark inspector occupies 25% width and reads WIND TUNNEL, LEVEL 2, Operational, Current effects, Upgrade to Level 3, Cost, Construction time; small current and next building thumbnails. One separate building under construction with scaffolding and crane. Keep UI text minimal and clear. Lower 25% of concept board is a labeled architectural progression strip WIND TUNNEL — VISUAL LEVELS with five equally sized tiles LEVEL 1 through LEVEL 5: distinct actual structural designs evolving from modest low shed with small external return duct to larger hall and control annex, then dedicated test complex, then sophisticated industrial aero campus. Same isometric angle, material family, lighting, landmark duct, and relative scale in all five. All levels fit same reserved parcel; higher levels fill more of it. Must clearly show changing architecture, not merely recoloring or bigger badges. Understated premium motorsport management aesthetic, no pixel art. This is a design proposal, all numbers illustrative.
